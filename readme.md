# 📈 Stock Market Tracker (MERN)

A simple full-stack web application to track real-time stock prices and visualize market trends. Built using the MERN stack (MongoDB, Express, React, Node.js).

---

## 🚀 Tech Stack

- **Frontend**: React, Tailwind CSS
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Others**: Axios, Chart.js, dotenv

---

## ✨ Features

- Search and track live stock prices
- Visual representation using charts
- Store favorite stocks in user account
- Responsive UI design
